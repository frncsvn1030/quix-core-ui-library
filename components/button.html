Button

A clickable element that lets users take actions or make choices.

#

Base

Refers to button's core, unstyled form, without specific visual distinctions.

<button class="qx-btn">Base Class</button>
#

Variants

Refers to button variants with a filled background color.

<button class="qx-btn qx-btn-primary">Primary</button>
<button class="qx-btn qx-btn-secondary">Secondary</button>
<button class="qx-btn qx-btn-success">Success</button>
<button class="qx-btn qx-btn-warning">Warning</button>
<button class="qx-btn qx-btn-error">Error</button>
<button class="qx-btn qx-btn-info">Info</button>
#

Outline

Refers to a button with a visible border but a transparent or light background.

<button class="qx-btn qx-btn-primary-outline">Primary</button>
<button class="qx-btn qx-btn-secondary-outline">Secondary</button>
<button class="qx-btn qx-btn-success-outline">Success</button>
<button class="qx-btn qx-btn-warning-outline">Warning</button>
<button class="qx-btn qx-btn-error-outline">Error</button>
<button class="qx-btn qx-btn-info-outline">Info</button>
#

Inverted

Refers to a button with a reversed color scheme, used for less critical actions to contrast with the main button.

<button class="qx-btn qx-btn-primary-inverted">Primary</button>
<button class="qx-btn qx-btn-secondary-inverted">Secondary</button>
<button class="qx-btn qx-btn-success-inverted">Success</button>
<button class="qx-btn qx-btn-warning-inverted">Warning</button>
<button class="qx-btn qx-btn-error-inverted">Error</button>
<button class="qx-btn qx-btn-info-inverted">Info</button>
#

Ghost and Link

Low-emphasis buttons for secondary actions. qx-btn-ghost fills on hover, and qx-btn-link looks like a text link.

<button class="qx-btn qx-btn-ghost">Ghost</button> <button class="qx-btn qx-btn-ghost qx-radius-md">Rounded ghost</button> <button class="qx-btn qx-btn-link">Link button</button>
#

Disabled

Refers that the button is currently not available for interaction.

<button class="qx-btn qx-btn-primary qx-btn-disabled">Primary</button>
<button class="qx-btn qx-btn-secondary" disabled>Secondary</button>
<button class="qx-btn qx-btn-primary-outline qx-btn-disabled">Primary</button>
<button class="qx-btn qx-btn-secondary-outline" disabled>Secondary</button>
#

Loader

Refers to a button which visually shows that an action is processing after it's clicked. Add qx-btn-loading for a built-in spinner that also blocks clicks.

<button class="qx-btn qx-btn-primary qx-btn-icon">
   <i class="fas fa-spinner fa-spin"></i>
</button>
<button class="qx-btn qx-btn-primary qx-btn-icon">
   <i class="fas fa-spinner fa-spin"></i>
   Loading
</button>
<button class="qx-btn qx-btn-primary-inverted qx-btn-icon">
   <i class="fas fa-spinner fa-spin"></i>
</button>
<button class="qx-btn qx-btn-primary-inverted qx-btn-icon">
   <i class="fas fa-spinner fa-spin"></i>
   Loading
</button>
<button class="qx-btn qx-btn-primary qx-btn-loading">Saving</button>
<button class="qx-btn qx-btn-primary-outline qx-btn-loading">Saving</button>
#

With Icon

Refers to a button that uses a picture (icon) to show its purpose, often without text.

<button class="qx-btn qx-btn-primary qx-btn-icon qx-btn-icon-only">
   <i class="fas fa-copy"></i>
</button>
<button class="qx-btn qx-btn-primary qx-btn-icon">
   <i class="fas fa-copy"></i>
   Copy
</button>
<button class="qx-btn qx-btn-error-inverted qx-btn-icon qx-btn-icon-only">
   <i class="fa-regular fa-heart"></i>
</button>
<button class="qx-btn qx-btn-error-inverted qx-btn-icon">
   Heart
   <i class="fa-regular fa-heart"></i>
</button>
#

Sizes

Refers to the button's visible width and height.

<button class="qx-btn qx-btn-primary qx-btn-sm">Small</button>
<button class="qx-btn qx-btn-primary qx-btn-md">Medium</button>
<button class="qx-btn qx-btn-primary qx-btn-lg">Large</button>
#

Shapes

Refers to the geometric form or outline of a button

<button class="qx-btn qx-btn-primary qx-radius-sm">Small</button>
<button class="qx-btn qx-btn-primary qx-radius-md">Medium</button>
<button class="qx-btn qx-btn-primary qx-radius-lg">Large</button>
<button class="qx-btn qx-btn-primary qx-radius-pill">Pill</button>
#

Full Width

Refers to a button that spans the entire horizontal space of its container.

<button class="qx-btn qx-btn-primary qx-full-width">Full Width</button>
#

Button Group

Joins related buttons into one control. The inner corners square off, and the outer corners follow the shape class.

<div class="qx-btn-group"> <button class="qx-btn qx-btn-primary-outline qx-radius-md">Left</button> <button class="qx-btn qx-btn-primary-outline qx-radius-md">Middle</button> <button class="qx-btn qx-btn-primary-outline qx-radius-md">Right</button> </div> <div class="qx-btn-group"> <button class="qx-btn qx-btn-primary qx-radius-pill">Day</button> <button class="qx-btn qx-btn-primary-inverted qx-radius-pill">Week</button> <button class="qx-btn qx-btn-primary-inverted qx-radius-pill">Month</button> </div>
